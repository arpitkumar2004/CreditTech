# Table 6: API / DPI & Institutional Integration Framework

| Digital Public Infrastructure (DPI) Rail | National Deployment Status (2025–26) | CreditTech Integration Role & Protocol | Statutory Regulatory Anchor |
| :--- | :--- | :--- | :--- |
| **Account Aggregator (NBFC-AA)** | • 17 RBI-licensed AAs operational.<br>• **284.6M+** accounts linked nationally.<br>• Lending constitutes &gt;70% of total AA data pulls (Sahamati, 2025). | • Acts as a certified **Financial Information User (FIU)** via licensed AA gateway.<br>• Pulls structured bank statements and UPI transaction logs using signed DEPA consent artifacts.<br>• Transforms raw JSON transactions into monthly cashflow vectors. | RBI Master Directions — NBFC-Account Aggregator (2016, amended 2023) |
| **Unified Lending Interface (ULI / erstwhile PTPFC)** | • Launched nationally by RBI (Aug 2024).<br>• 12 live loan journeys (KCC, dairy, MSME).<br>• **₹27,000 Crore** disbursed across 600k loans (Dec 2024). | • Standardized dispatch connector: dispatches alternative credit score, confidence band, and Top-5 SHAP reasons to partner bank CBS.<br>• Consumes state land registry and dairy federation feeds without bilateral bank-by-bank integrations. | RBI Statement on Developmental and Regulatory Policies (Aug 2024) |
| **Open Credit Enablement Network (OCEN 4.0)** | • Open API specification maintained by CredAll.<br>• Standardises borrower consent, loan application, offer presentation, and repayment schedule. | • Implements the standardized **Lending Service Provider (LSP)** API contract.<br>• Enables partner banks (RRBs/SFBs) to fetch standardized applicant dossiers with zero custom integration overhead. | Open Credit Enablement Network Protocol Standards (v4.0, 2024) |
| **Aadhaar e-KYC &amp; DigiLocker** | • Universal biometric and OTP identity verification across 1.4B population.<br>• DigiLocker holds 6B+ authentic digital documents. | • Seamless borrower identity verification during onboarding.<br>• Pulls authentic caste/domicile/land certificates directly from state digital issuers when authorized by borrower. | Information Technology Act (2000) &amp; Aadhaar Act (2016) |
| **DPDP Consent Architecture** | • Digital Personal Data Protection Act (2023) &amp; DPDP Rules (Nov 2025).<br>• Phased statutory enforcement through May 2027. | • End-to-end consent lifecycle management: notice delivery in 8th Schedule Indic languages, explicit consent recording, and **60-second revocation handling**.<br>• Immutable SHA-256 hash-chained consent ledger with 7-year audit log. | Ministry of Electronics and IT (MeitY) DPDP Rules 2025 |
