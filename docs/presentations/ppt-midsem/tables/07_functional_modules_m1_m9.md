# Table 7: Functional Modules (M1 to M9) System Specifications

| Module ID & Name | Primary Functional Responsibility | Input Data Artifacts | Output Artifacts & Invariants | Enforced Security & SLA Constraints |
| :--- | :--- | :--- | :--- | :--- |
| **M1: Onboarding &amp; Consent** | Manages multi-channel applicant registration, Aadhaar e-KYC, Indic language selection, and DPDP consent capture. | Mobile number, OTP, Aadhaar token, borrower intent payload. | Verified `Borrower` record, cryptographic `ConsentLedger` entry with SHA-256 hash. | SLA: &lt; 5 minutes; zero PII co-location; AES-256 field encryption. |
| **M2: Data Aggregation Engine** | Orchestrates asynchronous parallel calls to AA, Sentinel-2 satellite, e-Shakti SHG, and bureau rails. | Consent artifact reference, geo-coordinates, bank identifier. | Raw API payloads, normalized `FeatureSnapshot` vector (21 features). | SLA: &lt; 3 minutes; Graceful Degradation active on API timeout. |
| **M3: Alternative Scoring Engine** | Executes Champion WoE Scorecard and Challenger LightGBM to generate probability of default (PD) and credit score. | Anonymous normalized `FeatureSnapshot` vector. | Standardized credit score (300–900), confidence band ($\pm 15$ to $\pm 45$), risk zone tag. | Inference Latency: &lt; 0.04 ms in-process; monotonic binning invariant. |
| **M4: Explainability &amp; SHAP** | Computes game-theoretic feature contributions and translates them into plain-language bilingual reason codes. | Trained model weights, borrower feature vector, population baseline. | Top-5 positive and negative score drivers in conversational Hindi and English. | Exact additivity: $\sum \phi_i = \text{Score} - \text{Base}$; zero Monte Carlo approximation error. |
| **M5: Fairness &amp; Drift Monitor** | Continuous evaluation of portfolio approval parity and covariate shift across village clusters. | Scored applicant cohort, demographic flags (gender, landholding size). | Disparate Impact Ratio (DIR), Population Stability Index (PSI) per cluster. | **Statutory Gate:** DIR $\ge 0.80$; PSI $&lt; 0.10$; automated deployment block (HTTP 409) if breached. |
| **M6: Lender Decision Cockpit** | Underwriter web interface displaying applicant profile, score, satellite NDVI health, and SHAP drivers. | Score record, SHAP waterfall data, satellite plot geometry. | Underwriter decision (`APPROVE`, `MANUAL_REVIEW`, `DECLINE`), credit limit, pricing. | Mandatory structured dissent reason logging if loan officer overrides model recommendation. |
| **M7: Loan Lifecycle &amp; Feedback** | Closed-loop tracking of EMI repayment, delinquency transitions, and loan maturity. | Core Banking / LMS disbursement and monthly EMI repayment feed. | Performance labels (`GOOD`, `DEFAULT`), rolling default rates by score decile. | Labels channeled into periodic champion/challenger retraining pipeline. |
| **M8: Grievance Redressal &amp; Appeal** | Borrower-facing dispute channel allowing farmers to challenge an adverse credit decision or request human re-evaluation. | Applicant grievance petition, contested feature claims (e.g. unrecorded crop sale). | Registered ticket with SLA timer, re-appraisal dossier, ombudsman audit log. | Mandatory response within 14 days per RBI digital lending guidelines. |
| **M9: Institutional Dashboard** | Portfolio monitoring analytics cockpit for NABARD, bank executives, and regulatory auditors. | Aggregate portfolio database (anonymized). | Real-time charts of approval rates, portfolio-at-risk (PAR90), gender inclusion, and regional PSI. | Role-Based Access Control (RBAC); strict read-only access with zero PII exposure. |
