# Table 5: Technology Stack & Architectural Decision Records (ADRs)

| Architectural Tier | Selected Technology | Alternative Rejected | Concrete Engineering Justification & Trade-Offs |
| :--- | :--- | :--- | :--- |
| **Frontend Web Client** | **React 19 + Vite + Tailwind CSS + Lucide Icons** | Native Android (Kotlin) / Flutter | • Single unified responsive codebase for rural Bank Sakhi tablets (touch-first PWA) and Underwriter desktop cockpits.<br>• Offline-tolerant service workers cache static forms.<br>• Zero app-store distribution latency or user install friction. |
| **API & Backend Framework** | **Python 3.12 + FastAPI (Modular Monolith)** | Go / Spring Boot / Node.js Express | • Native Python ecosystem integration allows serving Scikit-Learn and LightGBM models **in-process** (&lt; 0.04 ms inference).<br>• Fully asynchronous (`asyncio`) I/O for 4-rail parallel ingestion.<br>• OpenAPI 3.1 auto-generation for OCEN/ULI interop. |
| **Database & Persistence** | **PostgreSQL 16 + SQLAlchemy 2.0 (Async) + Alembic** | MongoDB / DynamoDB / Blockchain | • Strict ACID transactional guarantees required for financial decisioning.<br>• Row-level DDL triggers enforce **append-only immutability** for consent and grievance logs.<br>• Physical isolation of encrypted PII from anonymous feature tables. |
| **Machine Learning Engine** | **Champion: Monotonic WoE Scorecard (Logistic Regression)**<br>Challenger: Monotonic LightGBM | Deep Neural Networks (PyTorch) / XGBoost Ensemble | • WoE Scorecard provides **regulatory transparency** under RBI/Basel Accords.<br>• Guarantees exact closed-form Shapley additivity ($\phi_i = \beta_i(\text{WoE}_i - \bar{\text{WoE}}_i)$).<br>• Captures 98% of ensemble AUC (0.9599 vs 0.9793) while executing in 0.038 ms. |
| **Explainable AI (XAI)** | **Bilingual SHAP (TreeSHAP &amp; Closed-Form Scorecard SHAP)** | LIME / Permutation Importance | • SHAP satisfies mathematical Game Theory axioms (Local Accuracy, Missingness, Consistency).<br>• Local point contributions translate directly into bilingual reason codes (Hindi + English) for adverse action notices. |
| **DPI Integration Protocols** | **Sahamati AA SDK + OCEN 4.0 API + ULI REST Connectors** | Custom Proprietary Bank APIs | • Adheres strictly to national digital public infrastructure standards.<br>• Prevents vendor lock-in with any single bank; enables plug-and-play scaling across multiple Regional Rural Banks (RRBs). |
| **Security & Privacy Layer** | **AES-256-GCM + SHA-256 Hash Chaining + mTLS** | Hyperledger Fabric Blockchain | • Provides mathematical tamper-evidence for consent chains at **zero gas or token cost**.<br>• Background `DataRetentionWorker` executes automated cryptographic wipes of expired borrower PII after 30-day underwriting TTL. |
| **Deployment & MLOps** | **Docker Containers + Nginx Reverse Proxy + Linux VM** | Kubernetes (EKS/GKE) / SageMaker Endpoints | • At pilot volumes (15–30 decisions/day), Kubernetes introduces excessive complexity, node spin-up latency, and cloud bills.<br>• In-process model execution eliminates costly remote ML endpoints. |
