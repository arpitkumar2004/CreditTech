# Table 8: End-to-End User Journey, Process Flows & Service Level Agreements (SLAs)

| Step # & Journey Phase | Primary Actor & Channel | Underlying System / Data Rail | Ingestion / Processing Transformation | Target SLA | Fallback / Graceful Degradation Protocol |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Application Initiation** | Farmer / SHG Member via Mobile PWA or Bank Sakhi Tablet | Frontend Client (`apps/borrower-app/`), FastAPI Gateway | Captures basic demographic intent, loan purpose, and selected Indic regional language. | **&lt; 5 minutes** | Offline PWA caching enables paper form recording if cellular connectivity is unavailable. |
| **2. Identity Verification & Consent** | Borrower assisted by Bank Sakhi (Community Operator) | Aadhaar e-KYC, DigiLocker, Account Aggregator Gateway | OTP / Biometric verification; signs DEPA consent artifact; appends block to SHA-256 consent ledger. | **&lt; 5 minutes** | DigiLocker document pull fallback if Aadhaar OTP gateway experiences cellular delay. |
| **3. Parallel Multi-Rail Ingestion** | Automated Orchestrator (Backend Engine) | 4-Rail Async Engine (AA, Sentinel-2, e-Shakti, Bureau) | Parallel API requests executed via Python `asyncio`; raw payloads parsed into normalized feature store vectors. | **&lt; 3 minutes** | **Graceful Degradation:** If satellite API times out (e.g. monsoon cloud cover), engine rescales weights and widens confidence interval ($\pm 45$ vs $\pm 15$). |
| **4. Alternative Score & SHAP Generation** | Automated Intelligence Engine | Champion Monotonic WoE Scorecard + TreeSHAP Engine | Maps 21 domain features to calibrated score (300–900); generates Top-5 reason codes in conversational Hindi and English. | **&lt; 2 minutes** | Scikit-learn / LightGBM executed **in-process** (&lt; 0.04 ms latency); zero external cloud API latency. |
| **5. Loan Officer Appraisal** | Bank / PACS Loan Officer (Underwriter) | Lender Decision Cockpit (`apps/borrower-app/`) | Displays applicant risk tier, satellite NDVI crop health, cashflow regularity, and SHAP reason drivers. | **Same Working Day** | If underwriter overrides model decision, system mandates logging a structured dissent code for audit. |
| **6. Sanction & Disbursal** | Regulated Entity (Bank / RRB Core Banking System) | ULI Gateway / Direct CBS Integration | Issues digital sanction letter; dispatches KCC crop credit straight to borrower's savings bank account. | **Per Bank SLA** (&lt; 24 hrs target) | Direct account credit via NEFT/IMPS; Key Facts Statement (KFS) sent via SMS/WhatsApp in local language. |
| **7. Repayment & Model Feedback Loop** | Borrower / Bank CBS / MLOps Engine | Closed-Loop MLOps Pipeline (`ml/monitoring/`) | Tracks monthly EMI repayment; identifies early delinquency; updates rolling default rates for quarterly retraining. | **Continuous** (Monthly) | Closed-loop retraining ensures model adapts to macro-climatic shifts and economic policy changes. |
| **8. Statutory DPDP Purge** | Automated Background Worker (`DataRetentionWorker`) | PostgreSQL Persistence Layer | Section 8(7) DPDP storage limitation: executes cryptographic wipe of raw borrower PII upon 30-day TTL expiry. | **Automated** (30-day TTL) | Preserves anonymized mathematical feature distributions for population drift audits while scrubbing PII. |
